# 📈 StockMarketSignalistApp

A real-time financial tracking and technical analysis web platform built with Next.js (App Router) and TypeScript. The application delivers live market data, interactive charting, and algorithmic trade signals to streamline portfolio decision-making.

## 🎯 Features

- **Real-Time Market Tracking:** High-frequency price updates, ticker monitors, and live quote aggregation for major equities.
- **Algorithmic Signal Engine:** Automated buy/sell momentum signals computed across multi-timeframe indicators (RSI, MACD, Moving Averages).
- **Interactive Financial Charts:** Responsive candlestick and line charts equipped with volume overlays and timeframe switching.
- **Watchlist & Portfolio Management:** Persistent tracking for monitored assets with calculated daily gains, losses, and volatility metrics.
- **Server-Side Optimization:** Next.js App Router architecture leveraging React Server Components (RSC) for fast data fetching and zero-CLS initial loads.

---

## 🛠 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React Server Components)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Charts:** Lightweight Charts / Recharts / Chart.js
- **Icons:** [Lucide React](https://lucide.dev/)
- **Data Layer:** WebSockets / Financial REST APIs
- **Typography:** [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) (Geist)
